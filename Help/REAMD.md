# Help!

## Descrição
Calcular o placar de uma competição a partir das submissões dos participantes.

## Lógica da solução
O programa conta os problemas resolvidos corretamente e soma o tempo da primeira submissão correta de cada problema, adicionando 20 minutos por tentativa incorreta anterior.

## Arquivos
- entrada.txt: submissões dos problemas.
- saida.txt: quantidade de problemas resolvidos e penalidade total.
- help.py: código Python.

## Como executar
Execute `python help.py` no terminal, dentro da pasta do desafio.
